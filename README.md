# Bank Management System 

    Objective
A simple console-based Java application that demonstrates the four core Object-Oriented Programming (OOP) principles:  
- Classes and Objects  
- Encapsulation  
- Inheritance  
- Polymorphism  

   How to Compile and Run
1. Clone this repository.  
2. Navigate to the `src` folder.  
3. Compile all files:
   ```bash
   javac Account.java SavingsAccount.java CheckingAccount.java Bank.java
